## Detail Temuan & Status Penyelesaian

### [Tier 1: Hard Gate - Priority: HIGH]

1. **[F-01] [R-02 / C-2] Rules of Hooks Violation (Conditional Hook Calls) di `NewUnitModal.jsx`**
   - **Status**: **RESOLVED**
   - **Perbaikan**: Memindahkan statemen `if (!isOpen) return null;` ke bawah setelah seluruh 17 deklarasi hook (`useState` & `useRef`). Menambahkan input tahun berlaku pajak dan tahun kaleng yang sebelumnya belum terhubung.
   - **Bukti**: 17 error hook pada oxlint terselesaikan menjadi 0 error.

2. **[F-02] [R-24 / C-2] Dead Mock Alert Handlers di `OwnerFinancialReport.jsx`**
   - **Status**: **RESOLVED**
   - **Perbaikan**: Mengganti browser `alert()` palsu dengan komponen modal cetak slip komisi mandiri (`CommissionSlipModal`) yang menampilkan rincian komisi per sales, breakdown transaksi motor yang terjual, nomor SPK, dan tombol cetak dokumen resmi (`window.print()`).
   - **Bukti**: Tidak ada lagi mock alert. Setiap tombol "Cetak Slip" membuka slip komisi siap cetak.

3. **[F-03] [R-18 / C-5] Hardcoded Multiplier HPP Fiktif (88%) di `OwnerFinancialReport.jsx`**
   - **Status**: **RESOLVED**
   - **Perbaikan**: Mengirimkan prop `units` dari `App.jsx` ke `OwnerFinancialReport.jsx` dan mengkalkulasi HPP riil per unit motor yang telah laku (`purchase_price` + akumulasi biaya servis bengkel) dengan fallback cerdas hanya jika data historis belum lengkap.
   - **Bukti**: Laporan laba/rugi kini mencerminkan modal riil pengadaan unit dan biaya perbaikan.

4. **[F-04] [R-24 / C-2] Dead State & Missing Search Input di `EmployeeManagement.jsx`**
   - **Status**: **RESOLVED**
   - **Perbaikan**: Menambahkan input live search karyawan (berdasarkan nama dan posisi) dan menghubungkan prop `currentRole` & `onSwitchUser` ke tombol aksi cepat peralihan sesi pengguna di panel header.
   - **Bukti**: Fitur pencarian karyawan berfungsi realtime dan pergantian role aktif dapat dilakukan langsung dari modul tim.

5. **[F-05] [R-24 / C-2] Dead State Pencarian di `TempoMonitor.jsx`**
   - **Status**: **RESOLVED**
   - **Perbaikan**: Menghubungkan `searchTerm` ke search bar baru pada panel filter untuk memfilter data tempo secara instan berdasarkan nama pembeli maupun plat nomor kendaraan. Menambahkan tampilan kartu responsif untuk perangkat bergerak.
   - **Bukti**: Input pencarian aktif dan memfilter daftar piutang tempo dengan instan.

### [Tier 3: Quality Locks - Priority: LOW]

11. **[F-11] [R-32 / Typography & Branding] Mismatch Tipografi 'Fredoka' pada Sistem ERP & Dokumen Cetak SPK**
    - **Status**: **RESOLVED**
    - **Perbaikan**: Mengganti font Google 'Fredoka' (bubble/kartun) dengan `Plus Jakarta Sans` berbobot 300..800 dikombinasikan dengan `JetBrains Mono` untuk angka tabular di `index.html` dan `src/index.css`. Memastikan `@media print` untuk SPK dan Kwitansi menggunakan font tegas dan formal.
    - **Bukti**: Tampilan visual tajam, elegan, dan dokumen cetak SPK sah berwibawa.

12. **[F-12] [R-33 / Mobile Layout] Kompatibilitas Tabel & Tap Target pada Layar Ponsel**
    - **Status**: **RESOLVED**
    - **Perbaikan**: Menambahkan kartu data alternatif responsif untuk layar `< md` pada `Dashboard.jsx`, `TempoMonitor.jsx`, dan tombol aksi dengan tap target minimum 44px.
    - **Bukti**: Penggunaan sistem di ponsel mekanik/sales di lapangan berjalan nyaman tanpa terpotong.

13. **[F-13] [R-34 / Accessibility] Kurangnya Accessible Name (`aria-label`) pada Tombol Icon-Only**
    - **Status**: **RESOLVED**
    - **Perbaikan**: Menambahkan atribut `aria-label` deskriptif pada seluruh tombol icon-only (tombol tutup modal `<X />`, toggle navbar, tombol aksi cepat, tombol cetak).
    - **Bukti**: Skrining aksesibilitas HTML5 terpenuhi untuk screen reader dan keyboard navigation.

14. **[F-14] [R-35 / Tone & Indonesian Copy] Konsistensi Kosakata Operasional Showroom**
    - **Status**: **RESOLVED**
    - **Perbaikan**: Menyelaraskan istilah campuran menjadi bahasa Indonesia baku untuk operasional showroom (misal: "Unit Tersedia", "Penjualan & Kasir", "Surat Perjanjian Jual Beli", "Riwayat Servis Bengkel", "Laporan Keuangan Owner").
    - **Bukti**: Navigasi dan teks antarmuka seragam, ramah pengguna, dan profesional.
